# 🚗 AI-Based Smart Parking System

## 📌 Overview

The **AI-Based Smart Parking System** is a full-stack web application that combines **Artificial Intelligence, Computer Vision, and Web Development** to provide an intelligent parking management solution.

The system allows users to register, log in, view real-time parking availability, reserve parking slots, and manage their bookings. Using **YOLOv8** and **OpenCV**, the AI module detects vehicles from a parking lot video or camera feed, identifies occupied and available parking slots, and updates the parking status automatically.

An admin dashboard enables efficient management of users, bookings, and parking slots, making the system suitable for smart campuses, shopping malls, offices, and public parking areas.

## 🚀 Features

### 🔐 Authentication

* Secure user registration and login
* Password encryption
* Session-based authentication
* Protected user and admin routes

### 🚗 Smart Parking Management

* View real-time parking availability
* Display available and occupied parking slots
* Book parking slots online
* Cancel bookings (before parking time)
* View booking history

### 🤖 AI-Based Parking Detection

* Vehicle detection using **YOLOv8**
* Parking slot occupancy detection using **OpenCV**
* Automatic counting of available and occupied slots
* Real-time parking status updates

Manage:

### 📊 Analytics

* Total parking slots

* Parking occupancy overview
